# Cognitif Connexion Foot

```
football-vision-test/

  backend/    # Backend Python (Yuuk, etc.)
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Or from the repo root:

```bash
npm run dev
```

## Vercel

Set **Root Directory** to `frontend` in the Vercel project settings.
